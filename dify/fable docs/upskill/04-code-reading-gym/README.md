# 04 — Code Reading Gym

Reading code is a trainable skill with reps, not a talent. Four stations:

| File | Rep type | Interview round it trains |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts: inputs, outputs, invariants, side effects, failure modes | "Walk me through this code" |
| [02-trace-tables.md](02-trace-tables.md) | Follow one value through the system, step by step | Debugging rounds |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to real repo patterns | Code review rounds |
| [04-review-katas.md](04-review-katas.md) | Full fake-PR reviews with graded findings | Code review rounds |

House rules: write your answers down before reading the rubric (retrieval beats recognition); time-box each drill; say answers *aloud* at least once per session — interviews are spoken.
