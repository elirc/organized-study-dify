# Mission Learning Path

This suite turns the repo into a training campaign. Each mission gives you a concrete skill, exact files to inspect, annotated code, questions, and a self-grade.

## How The Mission System Works

- Tier 1 builds orientation: entry points, folders, simple components, basic routes, and navigation.
- Tier 2 builds tracing skill: state, hooks, side effects, API contracts, middleware, diffs, composition, and TypeScript.
- Tier 3 builds judgment: architecture decisions, bugs, performance, security, missing tests, and git history.

## Recommended Pacing

Do one mission per day if you are new to production codebases. Do two to three per day if you already know React and Flask. Do not skip the written answers; the goal is to train explanation under pressure.

## How To Self-Grade

Strong answers name the owner of each responsibility, cite file paths and line ranges, explain data shape changes, and identify at least one failure mode.

## Using Codex Without Losing Learning Value

Ask Codex for hints, critique, or a second explanation after your first attempt. Avoid asking for the finished answer before you have read the code.

Good prompt:

> I completed Mission 7. Here is my explanation. Challenge any weak assumptions and ask me two follow-up questions.
