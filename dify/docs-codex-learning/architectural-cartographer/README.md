# Architectural Cartographer

This suite is the guided map of Dify. It starts with the shape of the monorepo, then drills into frontend bootstrapping, service clients, backend routing, validation, service logic, database models, workflow execution, tests, and senior-level critique.

## Who This Is For

Use this if you want to become better at reading unfamiliar production code. It is written for a junior engineer growing toward mid-level and senior judgment: first learn where things live, then learn how contracts flow, then learn what to question.

## How To Use It

1. Start with `00-reading-map.md`.
2. Read the cited file ranges before reading the explanation.
3. In `01-junior-engineer.md`, focus on naming what each layer owns.
4. In `02-mid-level-engineer.md`, trace one full behavior end to end.
5. In `03-senior-engineer.md`, practice forming evidence-backed critiques.
6. Use `04-reference-suite.md` as a playbook while working on real changes.

## Checkpoints

Every checkpoint includes questions and a self-grade. Answer from memory first. Then reopen the cited code and revise. Strong answers cite files, identify boundaries, and name trade-offs.

## Difference From The Other Suites

The mission suite is active practice. The user-story suite is implementation planning. The technology suite teaches stack-specific patterns. This suite is the architecture spine that ties them together.
